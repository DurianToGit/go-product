## 每日学习模板（固定格式，适用于所有天）

1. 目标（30 秒）——今天要学会/完成什么（概念或功能、以及对应的项目任务）。

2. 文档阅读（30–45 分钟）——具体看哪篇官方文档 / 哪章教程（精确到章节或关键关键词）。优先顺序：官方文档 -> 官方示例 -> 高质量博客/源码阅读。

3. 实操编码（45–75 分钟）——把文档学到的内容马上在项目里落地（小任务、单元功能或 Demo）。

4. 验证 & 测试（15–30 分钟）——单元测试、手工接口测试、压力/并发简单验证。

5. 提交 & 记录（15 分钟）——写简短 commit、更新当天的学习笔记/README，并列出明天要点。

6. 保持每天 2 小时左右（灵活调整），但“读 + 写 + 测试 + 提交”四步必须完成。
