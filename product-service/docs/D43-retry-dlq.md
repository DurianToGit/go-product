## 1. 为什么不能无限重试
无限重试的问题是：

* 坏消息会一直卡住
* 消费资源被耗尽
* 队列里正常消息也会被拖慢

所以必须有： 最大重试次数
## 2. 可重试错误 vs 不可重试错误
#### 可重试错误
比如：
* 网络抖动
* 下游临时不可用
* 短暂锁冲突
#### 不可重试错误
比如：
* JSON 格式错误
* 必填字段缺失
* 业务参数非法
## 3. 当前 demo 的重试策略
重试策略通常都是延迟重试，比如：

| 重试次数（失败后） | 延迟时间 | Topic                     |
| ------------------ | -------- | ------------------------- |
| 第 1 次失败        | 1 秒     | `stock.deduct.retry.1s`   |
| 第 2 次失败        | 5 秒     | `stock.deduct.retry.5s`   |
| 第 3 次失败        | 30 秒    | `stock.deduct.retry.30s`  |
